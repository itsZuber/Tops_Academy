Question:
Create two variables: let user1 = 'Priya' and let user2 = user1. Change user1 to 'Riya' and print both variables. Then, create two arrays: let favApps1 = ['Instagram', 'Spotify'] and let favApps2 = favApps1. Push 'Zomato' to favApps1 and print both arrays. Observe and comment on the difference in behavior between primitive and reference types.

Answer:

let user1 = "Priya";
let user2 = user1;

user1 = "Riya";

console.log(user1);
console.log(user2);

let favApps1 = ["Instagram", "Spotify"];
let favApps2 = favApps1;

favApps1.push("Zomato");

console.log(favApps1);
console.log(favApps2);

// Strings are primitive types, so user2 keeps the old value.
// Arrays are reference types, so both variables refer to the same array.

Question:
Show the difference between primitive and reference types by creating a variable favFood = 'pizza' and another variable favFoodCopy = favFood. Change favFood to 'burger' and log both variables. Then, create an object zomatoUser with a property city, assign it to another variable, change the city in one, and log both objects.

Hint: Observe how changes affect primitives vs objects.

Answer:

let favFood = "pizza";
let favFoodCopy = favFood;

favFood = "burger";

console.log(favFood);
console.log(favFoodCopy);

let zomatoUser = {
city: "Ahmedabad"
};

let zomatoUserCopy = zomatoUser;

zomatoUser.city = "Mumbai";

console.log(zomatoUser);
console.log(zomatoUserCopy);

// Primitive values are copied separately.
// Objects are reference types, so both variables point to the same object.




Question:
Write a function showProfile that takes a name, followers, and isPremium (boolean) as arguments. Inside the function, use dynamic typing to assign a string to followers, then a number, and finally print the type of followers each time using typeof.

Answer:

function showProfile(name, followers, isPremium) {
followers = "500";
console.log(typeof followers);

followers = 500;
console.log(typeof followers);

console.log(name);
console.log(isPremium);

}

showProfile("Zuber", 100, true);
