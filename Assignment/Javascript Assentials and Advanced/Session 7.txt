Question:
Create an HTML page with a button labeled 'Add Song' — when the button is clicked, use onclick to instantly add a new card below showing a random song title from your favorite playlist.

Answer:

<!DOCTYPE html>
<html>
<head>
    <title>My Playlist</title>
</head>
<body>

    <button onclick="addSong()">Add Song</button>

    <div id="playlist"></div>

    <script>
        let songs = [
            "Love Story",
            "Perfect",
            "Believer",
            "Shape of You",
            "Night Changes"
        ];

        function addSong() {
            let randomIndex = Math.floor(Math.random() * songs.length);

            let card = document.createElement("div");

            card.innerHTML = songs[randomIndex];

            card.style.border = "1px solid black";
            card.style.padding = "10px";
            card.style.marginTop = "10px";
            card.style.width = "200px";

            document.getElementById("playlist").appendChild(card);
        }
    </script>

</body>
</html>

Question:
Build a simple Zomato-style food order form with a dropdown for cuisine and an input for quantity — use the onchange event on the dropdown to display a message showing which cuisine was selected.

<html>

Question:
Write a function addToCart that adds a product name to a visible cart section when a 'Add to Cart' button is clicked, but attach the click event using addEventListener instead of the onclick attribute.

Answer:

<!DOCTYPE html>
<html>
<head>
    <title>Shopping Cart</title>
</head>
<body>

    <h2>Product</h2>

    <p>Wireless Headphones</p>

    <button id="cartButton">Add to Cart</button>

    <h3>Cart</h3>

    <div id="cart"></div>

    <script>
        function addToCart() {
            let product = document.createElement("p");

            product.innerHTML = "Wireless Headphones";

            document.getElementById("cart").appendChild(product);
        }

        let button = document.querySelector("#cartButton");

        button.addEventListener("click", addToCart);
    </script>

</body>
</html>

Question:
Display a list of 3 movies (hardcoded) and add a 'Remove' button next to each. Use addEventListener to remove the movie card from the DOM when its button is clicked.

Answer:

<!DOCTYPE html>
<html>
<head>
    <title>Movies</title>
</head>
<body>

    <div class="movie">
        <span>Avengers: Endgame</span>
        <button class="remove">Remove</button>
    </div>

    <div class="movie">
        <span>3 Idiots</span>
        <button class="remove">Remove</button>
    </div>

    <div class="movie">
        <span>Interstellar</span>
        <button class="remove">Remove</button>
    </div>

    <script>
        let buttons = document.querySelectorAll(".remove");

        buttons.forEach(function(button) {
            button.addEventListener("click", function() {
                button.parentElement.remove();
            });
        });
    </script>

</body>
</html>

Question:
Display the X and Y coordinates of the mouse when you click anywhere inside a div by using the event object in your click event handler.

Answer:

<!DOCTYPE html>
<html>
<head>
    <title>Mouse Coordinates</title>
</head>
<body>

    <div id="box" style="width:400px; height:200px; border:1px solid black;">
        Click anywhere inside this box
    </div>

    <p id="coordinates"></p>

    <script>
        let box = document.getElementById("box");

        box.addEventListener("click", function(event) {
            document.getElementById("coordinates").innerHTML =
                "X: " + event.clientX + " Y: " + event.clientY;
        });
    </script>

</body>
</html>

Question:
Briefly explain (in 2-3 sentences) what event flow is in the DOM, and give one example of how event bubbling could affect a shopping cart app like Flipkart.

Answer:

Event flow is the way an event moves through the DOM, from the parent elements to the target element and then back through the parent elements. Event bubbling can affect a shopping cart app if a button is inside a product card and clicking the button also triggers a click event on the product card, which may open the product details or perform another action.
