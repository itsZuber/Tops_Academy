Question 1: Create an HTML file named welcome.html, add a <script> tag, and display an alert with the message 'Welcome to your Playlist Builder!' when the page loads.

    alert("Welcome to your Playlist Builder!");
</script>

</body> 
</html>

Question 7:
Add a <button> to your HTML file labeled 'Show Bio', and use JavaScript inside a <script> tag to display an alert with your name and favorite app when the button is clicked.

Answer:

<!DOCTYPE html>

<html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Show Bio</title> </head> <body>

<button id="showBio">Show Bio</button>

<script>
    document.querySelector("#showBio").addEventListener("click", function() {
        alert("My name is Zuber and my favorite app is Instagram.");
    });
</script>

</body>
</html>

Question 9: Modify your insta-bio.html file to add a <button> labeled 'Show Greeting'. When the button is clicked, use JavaScript to show an alert that says 'Hello from JS!'.

Hint: Use document.querySelector and addEventListener to connect the button with your JS code.

Answer:

<!DOCTYPE html>

<html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Insta Bio</title> </head> <body>

<button id="showGreeting">Show Greeting</button>

<script>
    document.querySelector("#showGreeting").addEventListener("click", function() {
        alert("Hello from JS!");
    });
</script>

</body> </html>


Question 10: Edit your HTML file to include a <h2> tag with the text 'Top 3 Food Apps'. Use JavaScript in a <script> tag to change the color of this heading to green when the page loads.

Hint: Use document.querySelector to select the heading and style.color to change its color.

Answer:

<!DOCTYPE html>

<html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Food Apps</title> </head> <body>

<h2>Top 3 Food Apps</h2>

<script>
    document.querySelector("h2").style.color = "green";
</script>

</body> 
</html>
