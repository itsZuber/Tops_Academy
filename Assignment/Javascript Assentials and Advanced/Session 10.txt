Write a function orderFood(item, quantity = 1) that returns a string like 'You ordered 2 Burgers.' Use default parameters so that if quantity is not passed, it defaults to 1.

Answer:

    return `You ordered ${quantity} ${item}.`;
}

Question:
Given an object representing a Zomato order: const order = { item: 'Pizza', price: 350, user: 'Amit' }, use object destructuring to extract item and price into variables, then log a message like 'Amit ordered Pizza for ₹350'.

Answer:

const order = {
    item: "Pizza",
    price: 350,
    user: "Amit"
};

const { item, price, user } = order;

console.log(`${user} ordered ${item} for ₹${price}`);

Question:
Refactor this function to use an arrow function and rest parameters: function addToCart() { let total = 0; for(let i=0; i<arguments.length; i++) { total += arguments[i]; } return total; } The new function should be called addToCartArrow and accept any number of prices as arguments, returning their sum.

Answer:

const addToCartArrow = (...prices) => {
    let total = 0;

    for (let i = 0; i < prices.length; i++) {
        total += prices[i];
    }

    return total;
};

console.log(addToCartArrow(100, 200, 300));

Question:
Write an arrow function called getFollowersSummary that takes any number of follower counts (using the rest operator), sums them, and returns a string like 'Total followers: 1200'. Call it with 3 sample numbers to test.

Answer:

const getFollowersSummary = (...followers) => {
    let total = 0;

    for (let i = 0; i < followers.length; i++) {
        total += followers[i];
    }

    return `Total followers: ${total}`;
};

console.log(getFollowersSummary(400, 300, 500));
