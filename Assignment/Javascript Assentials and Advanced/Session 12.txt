Question:
Use fetch() to get a list of posts from https://jsonplaceholder.typicode.com/posts and display the first 5 post titles in the browser console.

Answer:

fetch("https://jsonplaceholder.typicode.com/posts")
    .then(response => response.json())
    .then(posts => {
        for (let i = 0; i < 5; i++) {
            console.log(posts[i].title);
        }
    });

Question:
Send a POST request using fetch() to https://jsonplaceholder.typicode.com/posts with a JSON body containing a title and body (your own text), then log the response object and check if the id property is present in the response.

Answer:

fetch("https://jsonplaceholder.typicode.com/posts", {
    method: "POST",
    headers: {
        "Content-Type": "application/json"
    },
    body: JSON.stringify({
        title: "My New Post",
        body: "This is my own post content."
    })
})
.then(response => response.json())
.then(data => {
    console.log(data);

    if (data.id) {
        console.log("ID is present: " + data.id);
    } else {
        console.log("ID is not present");
    }
});

Question:
Chain fetch() promises to fetch user data from https://jsonplaceholder.typicode.com/users, parse the JSON response, and then display all user emails in a single alert box separated by commas.

Answer:

fetch("https://jsonplaceholder.typicode.com/users")
    .then(response => response.json())
    .then(users => {
        let emails = users.map(user => user.email);

        alert(emails.join(", "));
    });

Question:
Chain two fetch() calls: first, fetch a user from https://jsonplaceholder.typicode.com/users/2, then use that user's id to fetch their posts from https://jsonplaceholder.typicode.com/posts?userId=2, and finally log the user's name and the titles of their posts.

Answer:

fetch("https://jsonplaceholder.typicode.com/users/2")
    .then(response => response.json())
    .then(user => {
        console.log("User Name: " + user.name);

        return fetch("https://jsonplaceholder.typicode.com/posts?userId=" + user.id)
            .then(response => response.json())
            .then(posts => {
                for (let post of posts) {
                    console.log(post.title);
                }
            });
    });

Question:
Fetch a list of albums from https://jsonplaceholder.typicode.com/albums, then filter and display only those albums where the userId is 2. Show the filtered album titles in the console.

Answer:

fetch("https://jsonplaceholder.typicode.com/albums")
    .then(response => response.json())
    .then(albums => {
        let filteredAlbums = albums.filter(album => album.userId == 2);

        filteredAlbums.forEach(album => {
            console.log(album.title);
        });
    });
