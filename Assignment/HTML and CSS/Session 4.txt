Question 1:

Create an HTML file that uses semantic tags to build a simple blog post layout with <header> for the blog title, <nav> for navigation links (Home, Explore, About), <article> for the main post content, and <footer> for copyright information.

Answer:

Create a file named blog.html and write the following code:

<!DOCTYPE html>

<html> <head> <title>My Blog</title> </head> <body>

<header>
    <h1>My Food Blog</h1>
</header>

<nav>
    <a href="#">Home</a>
    <a href="#">Explore</a>
    <a href="#">About</a>
</nav>

<article>
    <h2>My Favorite Food</h2>
    <p>Food is an important part of our daily life. I enjoy trying different dishes and exploring new flavors.</p>
</article>

<footer>
    <p>Copyright 2026 My Food Blog</p>
</footer>

</body> </html>

Question 4:

Given a non-semantic HTML snippet for a movie review (using only <div> and <span>), refactor it to use appropriate semantic tags like <header>, <nav>, <article>, and <footer> for improved accessibility and SEO.

Answer:

The non-semantic structure can be changed to the following semantic HTML:

<!DOCTYPE html>

<html> <head> <title>Movie Review</title> </head> <body>

<header>
    <h1>Movie Review</h1>
</header>

<nav>
    <a href="#">Home</a>
    <a href="#">Movies</a>
    <a href="#">Reviews</a>
</nav>

<article>
    <header>
        <h2>Movie Name</h2>
    </header>

    <p>This movie has a good story, interesting characters and enjoyable scenes.</p>

    <p>Rating: 4 out of 5</p>
</article>

<footer>
    <p>Copyright 2026 Movie Reviews</p>
</footer>

</body> </html>
