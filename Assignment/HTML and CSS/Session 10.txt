Question 1:

Create a Bootstrap Navbar for a music playlist app like Spotify, including links for Home, Playlists, and Profile. Make sure it collapses into a hamburger menu on mobile.

Answer:

Create a file named navbar.html:

<!DOCTYPE html>

<html> <head> <title>Music Playlist</title>

<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">

</head> <body>

<nav class="navbar navbar-expand-lg navbar-dark bg-dark">

    <div class="container">

        <a class="navbar-brand" href="#">My Music</a>

        <button class="navbar-toggler" type="button" data-bs-toggle="collapse" data-bs-target="#navbarMenu">

            <span class="navbar-toggler-icon"></span>

        </button>

        <div class="collapse navbar-collapse" id="navbarMenu">

            <ul class="navbar-nav">

                <li class="nav-item">
                    <a class="nav-link" href="#">Home</a>
                </li>

                <li class="nav-item">
                    <a class="nav-link" href="#">Playlists</a>
                </li>

                <li class="nav-item">
                    <a class="nav-link" href="#">Profile</a>
                </li>

            </ul>

        </div>

    </div>

</nav>

<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>

</body> </html>

Question 4:

Create a Bootstrap Form for a Zomato-style restaurant review: include fields for name, rating (1-5 stars), and a review message, along with a submit button.

Answer:

Create a file named restaurant-review.html:

<!DOCTYPE html>

<html> <head> <title>Restaurant Review</title>

<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">

</head> <body>

<div class="container mt-4">

    <h1>Restaurant Review</h1>

    <form>

        <div class="mb-3">

            <label for="name" class="form-label">Name</label>

            <input type="text" class="form-control" id="name">

        </div>

        <div class="mb-3">

            <label for="rating" class="form-label">Rating</label>

            <select class="form-select" id="rating">

                <option selected>Select Rating</option>

                <option value="1">1 Star</option>

                <option value="2">2 Stars</option>

                <option value="3">3 Stars</option>

                <option value="4">4 Stars</option>

                <option value="5">5 Stars</option>

            </select>

        </div>

        <div class="mb-3">

            <label for="review" class="form-label">Review</label>

            <textarea class="form-control" id="review" rows="4"></textarea>

        </div>

        <button type="submit" class="btn btn-primary">Submit Review</button>

    </form>

</div>

</body> </html>
