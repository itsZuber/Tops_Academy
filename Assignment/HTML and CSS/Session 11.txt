Question 5:

Add a theme switcher button to your page that toggles between a light and dark background using Bootstrap classes, and updates the text color for readability. Hint: Use JavaScript to toggle 'bg-light'/'bg-dark' and 'text-dark'/'text-light' classes on the main container.

Answer:

Create a file named theme.html:

<!DOCTYPE html>

<html> <head> <title>Theme Switcher</title>

<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">

</head> <body>

<div id="mainContainer" class="container bg-light text-dark p-4">

    <h1>Movie Details</h1>

    <p>Welcome to the movie details page.</p>

    <button class="btn btn-primary" onclick="changeTheme()">
        Switch Theme
    </button>

</div>

<script>

    function changeTheme() {

        document.getElementById("mainContainer").classList.toggle("bg-light");

        document.getElementById("mainContainer").classList.toggle("bg-dark");

        document.getElementById("mainContainer").classList.toggle("text-dark");

        document.getElementById("mainContainer").classList.toggle("text-light");

    }

</script>

</body> 
</html>
