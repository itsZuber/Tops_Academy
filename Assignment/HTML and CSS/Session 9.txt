Question 3:

Design a BookMyShow-like movie details section using Bootstrap: place a movie poster image in one column and movie details (title, genre, rating, and a 'Book Now' button) in the second column, using the grid system.

Answer:

Create a file named movie.html:

Question 4:

Refactor your 2-column layout to be mobile-friendly: make the columns stack vertically on screens smaller than 576px using Bootstrap's responsive grid classes. Hint: Try using col-12 for xs and col-6 for md and above.

Answer:

Update the movie details section from Question 3 by using col-12 for mobile and col-md-6 for medium and larger screens:

<div class="container mt-4">

<div class="row">

    <div class="col-12 col-md-6">

        <img src="movie.jpg" class="img-fluid" alt="Movie Poster">

    </div>

    <div class="col-12 col-md-6">

        <h1>The Adventure</h1>

        <p>Genre: Action, Adventure</p>

        <p>Rating: 4.5/5</p>

        <button class="btn btn-primary">Book Now</button>

    </div>

</div>

</div>

On mobile screens, both columns use the full width and stack vertically.

On medium and larger screens, each column takes 50% of the row and appears side by side.
