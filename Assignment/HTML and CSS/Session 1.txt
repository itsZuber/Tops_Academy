QUESTION 2.) Create a simple HTML file named myprofile.html that displays your name, a short bio, and a profile picture using appropriate HTML tags (h1, p, img). Open it in your browser and view the result.

Answer:

I created a file named myprofile.html with the following HTML code:

<!DOCTYPE html>

<html> <head> <title>My Profile</title> </head> <body>

<h1>Zuber Shaikh</h1>

<p>I am learning software testing and web development.</p>

<img src="profile.jpg" alt="My Profile Picture" width="200">

</body> </html>

I saved the file as myprofile.html and opened it in the browser to view the profile page.

QUESTION 3.) Use Chrome DevTools to change the background color of your name (in myprofile.html) to any color you like, live in the browser, without editing the HTML file.

Answer:

I opened myprofile.html in Chrome and used Inspect Element to select the h1 tag.

In the Styles section of Chrome DevTools, I added the following CSS:

background-color: lightblue;

The background color of my name changed immediately in the browser.

I did not edit the original HTML file.
