Build a Myntra-like offer banner using internal CSS (inside a <style> tag) to set a custom font family, text color, and background color for the banner text.

</div>

</body> </html>

Question 3:

Create a separate CSS file named styles.css and link it to your HTML file. Use external CSS to style all <button> elements with a Zomato-inspired color, rounded corners, and a hover effect that changes the background color.

Answer:

Create two files named index.html and styles.css.

index.html:

<!DOCTYPE html>

<html> <head> <title>Button Styling</title> <link rel="stylesheet" href="styles.css"> </head> <body>

<button>Order Now</button>
<button>View Menu</button>

</body> </html>

styles.css:

button {
background-color: red;
color: white;
border: none;
border-radius: 10px;
padding: 10px 20px;
cursor: pointer;
}

button {
background-color: darkred;
}

Question 5:

Implement a simple light/dark mode switch for a BookMyShow movie detail page using internal CSS and a toggle button. When the button is clicked, switch between light and dark color themes for the page. Hint: Use JavaScript to add or remove a 'dark-mode' class on the <body> and define the color themes in CSS.

Answer:

Create a file named movie.html and write the following code:

<!DOCTYPE html>

<html> <head> <title>Movie Details</title>

<style>
    body {
        background-color: white;
        color: black;
    }

    .dark-mode {
        background-color: black;
        color: white;
    }
</style>

</head> <body>

<h1>Movie Details</h1>

<p>Movie Name: The Adventure</p>
<p>Rating: 4.5/5</p>

<button onclick="toggleMode()">Light / Dark Mode</button>

<script>
    function toggleMode() {
        document.body.classList.toggle("dark-mode");
    }
</script>

</body> </html>
