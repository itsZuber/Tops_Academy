Question 4:

Refactor your landing page to include a sticky navigation bar at the top using Bootstrap's navbar component, with links to Home, About, and Contact sections.

Answer:

Add the following navbar at the beginning of the <body>:

<nav class="navbar navbar-expand-lg navbar-dark bg-dark sticky-top">

<div class="container">

    <a class="navbar-brand" href="#">My Music</a>

    <button class="navbar-toggler" type="button" data-bs-toggle="collapse" data-bs-target="#menu">

        <span class="navbar-toggler-icon"></span>

    </button>

    <div class="collapse navbar-collapse" id="menu">

        <ul class="navbar-nav">

            <li class="nav-item">
                <a class="nav-link" href="#home">Home</a>
            </li>

            <li class="nav-item">
                <a class="nav-link" href="#about">About</a>
            </li>

            <li class="nav-item">
                <a class="nav-link" href="#contact">Contact</a>
            </li>

        </ul>

    </div>

</div>

</nav>

The class "sticky-top" keeps the navigation bar at the top while scrolling.
