Question 1:

Create an HTML file with a container div and 4 images of your favorite apps (Instagram, WhatsApp, Zomato, Spotify) as social icons. Use CSS Flexbox to display them in a row with equal spacing using justify-content.

Answer:

Create a file named app-icons.html:

<!DOCTYPE html>

<html> <head> <title>App Icons</title>

<style>
    .container {
        display: flex;
        justify-content: space-between;
    }

    .container img {
        width: 80px;
        height: 80px;
    }
</style>

</head> <body>

<div class="container">

    <img src="instagram.png" alt="Instagram">

    <img src="whatsapp.png" alt="WhatsApp">

    <img src="zomato.png" alt="Zomato">

    <img src="spotify.png" alt="Spotify">

</div>

</body> </html>

Question 4:

Make your product grid responsive: use grid-template-columns to show 3 columns on desktop, 2 columns on tablet, and 1 column on mobile screens. Hint: Use CSS media queries to change grid-template-columns based on screen width.

Answer:

Use the following CSS for the responsive product grid:

.product-grid {
display: grid;
grid-template-columns: repeat(3, 1fr);
gap: 20px;
}

@media (max-width: 768px) {
.product-grid {
grid-template-columns: repeat(2, 1fr);
}
}

@media (max-width: 480px) {
.product-grid {
grid-template-columns: 1fr;
}
}

On desktop, the grid displays 3 columns.

On tablet, it displays 2 columns.

On mobile, it displays 1 column.
