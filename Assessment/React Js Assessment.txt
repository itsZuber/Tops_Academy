Question 1:

You are building a food delivery app where each restaurant's details — name, cuisine type, and minimum order value — must remain constant throughout the session, but the currently selected dish should be updatable as the user browses the menu.

Which declaration keyword (var, let, or const) would you use for each variable — the restaurant name, the minimum order value, and the currently selected dish — and why? Explain how scope and reassignment rules influence your choices.

Answer:

I would use const for the restaurant name and minimum order value because their values should not change. I would use let for the currently selected dish because its value can change when the user selects another dish.

const and let are block-scoped. A const variable cannot be reassigned, while a let variable can be reassigned. var is function-scoped and can be redeclared, so I would prefer const and let in this situation.

Example:

const restaurantName = "Spice Garden";
const minimumOrderValue = 200;

let selectedDish = "Paneer Tikka";

selectedDish = "Veg Burger";

console.log(restaurantName);
console.log(minimumOrderValue);
console.log(selectedDish);

Answer:

I would create one reusable function called calculateGST(). It can receive the category and price and return the GST amount.

A function declaration is written using the function keyword and can be called before its declaration because of hoisting.

A function expression stores a function inside a variable. It is not available before the variable is initialized.

An arrow function is a shorter way to write a function.

For this shared utility, I would choose a function declaration because it is easy to read and it also supports hoisting.

Code:

function calculateGST(category, price) {
if (category === "Food") {
return price * 0.05;
} else if (category === "Beverage") {
return price * 0.18;
} else {
return 0;
}
}

Question:

Build a JavaScript app that fetches a restaurant list from a public API, displays the restaurant names as clickable items, saves a favourite restaurant in localStorage, highlights it, restores it after reload, shows loading text, and displays an error in the DOM if the request fails.

JavaScript Code:

const restaurantList = document.getElementById("restaurantList");
const loading = document.getElementById("loading");
const error = document.getElementById("error");

async function getRestaurants() {

try {
    const response = await fetch(
        "https://jsonplaceholder.typicode.com/users"
    );

    if (!response.ok) {
        throw new Error("Failed to load restaurants");
    }

    const restaurants = await response.json();

    loading.textContent = "";

    const favourite = localStorage.getItem("favouriteRestaurant");

    restaurants.forEach(function(restaurant) {

        const li = document.createElement("li");

        li.textContent = restaurant.name;

        if (restaurant.name === favourite) {
            li.classList.add("favourite");
        }

        li.addEventListener("click", function() {

            localStorage.setItem(
                "favouriteRestaurant",
                restaurant.name
            );

            const allItems =
                document.querySelectorAll("#restaurantList li");

            allItems.forEach(function(item) {
                item.classList.remove("favourite");
            });

            li.classList.add("favourite");
        });

        restaurantList.appendChild(li);
    });

} catch (err) {

    loading.textContent = "";

    error.textContent =
        "Sorry, restaurants could not be loaded.";
}

}
